## Overview
Four increasingly complex **left-hand-only** [[Arpeggio]] rhythm patterns, all built from the same C major [[Chord]] (C-E-G) — this lesson is about rhythm, not new notes.

> [!warning] Octave markings not fully captured
> The source marks some notes in **red** to mean "play this an octave higher," but that color distinction didn't survive extraction into plain text below — only the note letters did. **Check the actual video/PDF for exactly which notes shift up an octave** before treating these as complete.

## Key Concepts
- All 4 patterns use only C, E, G — see [[Chord]].
- Parentheses `( )` in the patterns below mark notes grouped/played closer together rhythmically (as shown in the source).

## The 4 Patterns

| <span style="background-color:#2c6fbb;color:#fff;padding:1px 6px;border-radius:3px;">Pattern</span> | <span style="background-color:#c9622a;color:#fff;padding:1px 6px;border-radius:3px;">Time Signature</span> | <span style="background-color:#3a8f5c;color:#fff;padding:1px 6px;border-radius:3px;">LH Pattern (C chord)</span> |
|---|---|---|
| Arpeggio 1 | 4/4 | C – G – C – G – E – G – C – G |
| Arpeggio 2 | 4/4 | C (G C) C (G C) · C (G C) (G C) · C (G C) |
| Arpeggio 3 | 4/4 | C (G C) (G C) · (C E G) (G C) |
| Arpeggio 4 | **3/4** | C (G C) (G C) · (C E G) (G C) |

Arpeggio 3 and 4 use the exact same note pattern — the only difference is the time signature (4/4 vs 3/4), which changes where the emphasis/counting falls.

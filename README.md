# 🎹 Piano

Personal notes and practice log from my piano learning journey, kept as an [Obsidian](https://obsidian.md) vault.

## How to use
1. Clone this repo.
2. In Obsidian: **Open folder as vault** → select this folder.
3. Start from [Home.md](Home.md).

## Structure
- `PIX Series YouTube Course/` — notes from the free [PIX Series](https://pixseries.com) YouTube playlist I'm currently following.
- `Glossary/` — atomic reference notes for recurring terms (Alankar, Sargam, fingering notation, ...), linked from lesson notes instead of repeating explanations.
- `Templates/` — starting template for new lesson notes.
- `Home.md` — vault dashboard / map of content.
- A `Paid Course/` folder will be added once I start one.

## Conventions
See [CLAUDE.md](CLAUDE.md) for the frontmatter schema and note-taking conventions used across this vault.

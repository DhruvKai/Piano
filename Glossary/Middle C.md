# Middle C

**Middle C** is the C closest to the middle of the keyboard. Song tutorials use it as the landmark for where to put your hands, e.g. "the C# one octave above middle C."

## How to find it
- Every C is the white key just left of a **group of two black keys** (see [[Octave]]).
- **88-key piano:** the 4th C from the left, usually right under the brand name.
- **61-key keyboard:** the 3rd C from the left.

## Octave numbers
Some sources number the octaves, and middle C is **C4**. The octave above it starts at C5, the one below at C3. The keys in between take the number of the C below them, so the A# right above middle C is A#4.

# Arpeggio

An **arpeggio** is a [[Chord]] played **one note at a time** instead of all together — same notes (root, 3rd, 5th), spread out into a sequence. Think of it as "unrolling" a chord.

## In this course
Arpeggios show up as a **left-hand** pattern (the broken chord) played underneath a **right-hand** melodic line — see [[Lesson 07 - Basic Arpeggios]] and [[Lesson 08 - Advanced Arpeggios]]. The left hand often repeats the broken chord while the right hand moves through a scale-like run above it, which is really the same two-hands-doing-different-things skill as [[Lesson 06 - Playing With Both Hands]].

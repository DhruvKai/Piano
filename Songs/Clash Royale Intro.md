## Overview
The short "game starting" sound from Clash Royale. It has **two parts**:
1. **Part 1:** a rising [[Arpeggio]] riff split across both hands, held at the end.
2. **Part 2:** a 6-note right-hand melody over three left-hand [[Chord|chords]].

Play them back to back. Both parts are short, so this is mostly about getting the riff **even** and lining the chords up with the right melody notes.

## Key Concepts
- [[Middle C]] is the reference point Amos uses to find each starting key.
- **Part 1** is a broken chord ([[Arpeggio]]) rolled from the lowest note to the highest. Each key stays down after you play it, so all five notes ring together at the end.
- **Part 2** uses two major [[Chord|chords]]: **D# major** and **C major**.

> [!tip] Hearing "flat" in the video?
> Amos says **"B flat"** and **"E flat"**. These are the same keys as **A#** and **D#** (see [[Sharps & Flats]]). This note uses the sharp names throughout.

## Part 1 — The Iconic Riff

| Order | Hand | Key | Where |
| ----- | ---- | --- | ----- |
| 1 | LH | C# | the C# one [[Octave]] above middle C |
| 2 | LH | F# | |
| 3 | LH | G# | |
| 4 | RH | C# | the next C# up |
| 5 | RH | F | |

![[Assets/Songs/Clash Royale Intro/clash-royale-riff.svg|360]]

- Play the five notes **one after another, from lowest to highest**, then **hold** them.
- Amos stresses that it must be **even and clear**: every note gets the same amount of time. If some notes rush and others drag, it "doesn't sound right."
- Practise it slowly first, as he does at [1:17](https://www.youtube.com/watch?v=zNyCPcqRJ9U&t=77s), then speed it up while keeping it even.

> [!note] What chord is this?
> C# – F – G# is a **C# major** chord (the F is the 3rd; on paper it's spelled E#). The **F#** added in the left hand gives the riff its suspended, "about to start" sound.

## Part 2 — Melody + Chords

**Right hand: melody.** It starts on the A# just above middle C.

`A# → A → F → G → D → C`

![[Assets/Songs/Clash Royale Intro/clash-royale-melody.svg|360]]

**Left hand: chords.** Use the octave just below middle C.

| Chord | Notes |
| ----- | ----- |
| D# major | D# + G + A# |
| C major | C + E + G |

![[Assets/Songs/Clash Royale Intro/clash-royale-ds-major.svg|360]]
![[Assets/Songs/Clash Royale Intro/clash-royale-c-major.svg|360]]

**How the hands line up.** A chord goes down together with the melody note above it. A blank cell means the left hand keeps holding the previous chord.

| RH melody | A# | A | F | G | D | C |
| --------- | -- | - | - | - | - | - |
| **LH chord** | **D# major** | | | **D# major** (again) | | **C major** |

So it's **3 chords in total**: D# major twice, then C major on the final note.

## Putting it together
Part 1 riff (held) → Part 2 melody + chords. At full speed, the Part 2 melody is a quick run that lasts about a second. Get it clean slowly first, as with the riff.

## Exercises / Practice
- [ ] Find middle C, then the C# one octave above it (the riff's first note)
- [ ] Part 1 slowly: 5 notes, perfectly even, all held
- [ ] Part 1 at full speed, still even
- [ ] RH melody alone: A# A F G D C
- [ ] LH chords alone: D# major → D# major → C major
- [ ] Part 2 hands together, slowly, chords landing on A#, G, and C
- [ ] Both parts back to back at full speed
